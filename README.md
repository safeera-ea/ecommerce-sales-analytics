E-Commerce Sales & Customer Analytics

A complete data analysis project covering SQL, Python, Excel, and Power BI — analyzing 9,994+ e-commerce transaction records to uncover sales trends and profitability insights.

🛠️ Tools & Technologies
- Database: MySQL
- Programming: Python (Pandas, NumPy, Matplotlib, Seaborn)
- BI & Visualization: Power BI, Excel
- Techniques: EDA, Statistical Analysis, Pivot Tables, VLOOKUP

 📊 Key Insights
- **West region**  the highest sales (₹730K), while **South** had the lowest
- **Technology** category delivered the highest profit share (50.8%)
- Sales showed clear seasonal peaks across the year

 📁 Project Structure
- `data/` — Raw dataset
- `sql/` — Database queries and analysis screenshots
- `python/` — Data cleaning, statistics, and visualizations
- `excel/` — Pivot tables and VLOOKUP screenshots
- `powerbi/` — Interactive dashboard and screenshots

## 🔍 What This Project Covers
1. Built a MySQL database with CRUD operations and multi-table queries
2. Cleaned and analyzed data using Python (Pandas)
3. Applied statistical analysis (mean, std deviation, distribution)
4. Created visualizations (bar, pie, distribution charts)
5. Built pivot tables and VLOOKUP functions in Excel
6. Designed an interactive Power BI dashboard with KPI cards and slicers
